# claude-code

Claude Code 전역 설정(`~/.claude`) 저장소. 이 저장소에 올라가는 것은 `CLAUDE.md`, `settings.json`, `skills/`, `agents/`, 이 문서뿐이다. 대화 기록, 로그인 정보, 메모리, 플러그인 캐시는 올리지 않는다.

## 스킬

`skills/` 폴더에 있다.

| 이름 | 설명 |
|---|---|
| find-skills | 필요한 기능에 맞는 스킬을 찾아 설치하도록 돕는 스킬 |
| grill-me | 계획이나 설계를 질문으로 파고들어 함께 다듬는 스킬. `/grill-me`로만 호출한다 |
| ponytail | 가장 작은 변경으로 문제를 해결하고 짧게 답하게 하는 스킬 |
| ponytail-review | 변경 사항의 로직, 보안, 부하, 테스트, 불필요한 코드를 검토하는 스킬 |

## 에이전트

`agents/` 폴더에 있다.

| 이름 | 설명 |
|---|---|
| ponytail-reviewer | ponytail-review 스킬을 가지고 코드 변경을 읽기 전용으로 검토하는 에이전트 |

## 훅

| 이름 | 설명 |
|---|---|
| 없음 | 전역 설정에 직접 등록한 훅은 없다. superpowers 플러그인에 포함된 세션 시작 훅은 플러그인을 꺼 두어 동작하지 않는다 |

## MCP

이 저장소에는 없고 컴퓨터마다 따로 등록한다.

| 이름 | 설명 |
|---|---|
| github | GitHub 저장소, 이슈, PR을 조회하고 수정하는 MCP. 사용자 범위로 `~/.claude.json`에 등록하며 토큰이 들어 있어 저장소에 올리지 않는다 |
| Context7 | 라이브러리와 프레임워크의 최신 문서를 조회하는 MCP. claude.ai 계정의 커넥터로 연결한다 |

## 플러그인

`settings.json`의 `enabledPlugins`와 `extraKnownMarketplaces`에 기록되어 있다. 플러그인 파일 자체는 올리지 않으며, 다른 컴퓨터에서는 이 설정을 보고 다시 설치한다.

| 이름 | 설명 |
|---|---|
| frontend-design | 화면을 만들거나 고칠 때 색, 글꼴, 배치 방향을 정하도록 돕는 플러그인. 켜져 있다 |
| ui-ux-pro-max | 스타일, 색상표, 글꼴 조합, UX 지침 데이터로 UI를 설계하고 검토하는 플러그인. 켜져 있다. 검색 도구를 쓰려면 Python 3가 필요하다 |
| superpowers | 브레인스토밍, 계획 작성, 테스트 주도 개발 같은 개발 절차 스킬을 묶은 플러그인. 설치만 하고 꺼 두었다 |
